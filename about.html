The project and the people

Skipping the work is a research project for COMP3821 at UNSW Sydney. We studied how to find the best long-run average reward in a deterministic MDP, proposed a cheap test that lets a solver skip parts of the graph, proved it safe, and measured when it pays off.

What we proved

Write $\lambda(K)$ for the best cycle mean inside an SCC $K$, $D(K)$ for the best gain you can reach by leaving it, and $D_k(v)$ for the most reward a $k$-step walk inside $K$ can collect on its way to $v$. Then $\delta_k(K) = \max_v \bigl(D_k(v) - D_{k-1}(v)\bigr)$.

Soundness

The bounds never undershoot

For every SCC with a cycle and every $k \ge 1$: $\delta_k(K) \ge \lambda(K)$, $\;\delta_{k+1}(K) \le \delta_k(K)$, and the largest edge weight $M(K) = \delta_1(K)$.

So if any bound is at most $D(K)$, no cycle inside $K$ beats leaving, and skipping $K$ is safe. Each extra row of Karp's table can only tighten the bound.

Exactness

Skipping never changes the answer

With exact arithmetic and sound bounds, the cascade returns $g^*(v)$ for every state $v$, whichever tests are switched on.

The proof goes SCC by SCC, sinks first: by the time an SCC is reached, everything it can step into already has its right gain.

Running time

Pay only for what you solve

$O\bigl(n + m + \sum_{K \text{ solved}} n_K m_K + \sum_{K \text{ skipped}} k_K m_K\bigr)$, where $k_K$ is the number of rows built before $K$ was skipped. In the worst case that is $O(nm)$, the same as plain Karp, and a single SCC reaches it.

A skipped SCC costs only the rows it took to rule it out, and the tests themselves are paid for by those rows.

What was known, and what is ours

Established before us

  • A deterministic MDP's optimal gain from a state is the best mean of a cycle reachable from it (Puterman 1994; Karp 1978).
  • Karp's algorithm finds the best cycle mean of a strongly connected graph in O(nm) time (Karp 1978).
  • The gain is constant on each SCC, so SCCs can be solved one at a time, sinks first (folklore; compare Ashok et al. 2017).
  • Reading the best cycle off Karp's table the way Karp suggested can fail (Chaturvedi and McConnell 2017).
  • Howard's policy iteration is usually the fastest in practice (Dasdan 2004), but there are graphs where it needs many iterations (Asadi, Chatterjee and de Raaij 2025).

Ours

  • The cascade: test an SCC with cheap upper bounds before solving it, and skip it when a bound is no better than leaving. The δk bound reuses the rows Karp would build anyway.
  • Proofs that the bounds are sound, that the cascade is exact, and of its running time.
  • The hybrid: the cheapest test, then Howard on each SCC that is left, with Karp as a fallback.
  • The dmdp library and seven experiments on 136 graphs.

Related ideas exist: action elimination for MDPs (MacQueen 1967; Grinold 1973), topological value iteration (Dai et al. 2011), and stopping Karp early (Hartmann and Orlin 1993; Dasdan and Gupta 1998). The cascade belongs to the same family: sound bounds, used to avoid work.

Code and data

The library

dmdp, in C++: Tarjan's SCCs, Karp, the cascade, Howard, the hybrid, exact fractions, a brute-force checker, and dmdp viz, which records a run step by step for this site.

The graphs

Generated families that test one thing at a time, real circuits from Dasdan's benchmark suite, and Asadi et al.'s family that is hard for Howard.

This site

TypeScript and plain SVG, with KaTeX for the maths. Every run you watch was recorded by the library at one pinned commit. Source on GitHub.
